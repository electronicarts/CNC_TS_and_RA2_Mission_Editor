# Языки интерфейса и названия объектов

В этой сборке доступны English, Deutsch, Русский, Українська и Español.

Откройте **Options → Settings → Language / Sprache**, выберите язык и нажмите
**OK**. Меню, дерево объектов и подписи диалогов обновляются сразу. Выбор
сохраняется в `%LOCALAPPDATA%\FinalAlert 2\FinalAlert.ini` и восстанавливается
при следующем запуске. Языковые файлы находятся в папке `Translations` рядом
с EXE. При переносе сборки копируйте весь каталог редактора.

Язык интерфейса и язык названий игровых объектов независимы. Названия берутся
из `RA2.CSF` или `RA2MD.CSF` установленной игры. Некоторые старые русские
издания хранят байты Windows-1251 в позициях Unicode U+00xx. Например,
`Èíòðî` вместо `Интро`. Редактор распознаёт такой формат по содержимому всего
файла и исправляет строки в памяти перед заполнением списков. Игровые CSF/MIX
и карты при этом не изменяются. Обычные Unicode-файлы, в том числе украинские
и испанские, не требуют преобразования.

Для нестандартных модов можно явно выбрать способ чтения в пользовательском
`FinalAlert.ini`, после чего перезапустить редактор:

```ini
[FinalAlert]
GameStringEncoding=auto
```

- `auto` — распознавание старого русского формата (по умолчанию).
- `unicode` — использовать исходный Unicode без исправлений.
- `windows-1251` — принудительно исправлять строки старого русского формата.

Режим `auto` требует достаточно большого образца, в котором символы U+00C0–FF
преобладают над латинскими ASCII-буквами. Для маленьких или смешанных таблиц
модов используйте явный режим. Строки с уже записанной кириллицей сохраняются.
Выбранный формат записывается в `finalalert2log.txt` в папке настроек редактора.

## Проверки исходников

`MissionEditor/tests/test_localization.py` проверяет переводы с учётом реальных
правил INI-парсера: покрытие строк и подписей ресурсов, дубликаты, плейсхолдеры,
фильтры файлов, переносы строк, горячие клавиши и экранирование ключей.
`MissionEditor/tests/CsfTextTest.cpp` — самостоятельный тест Win32 для v143:
распознавание кодировки, сохранение Unicode и безопасное чтение обрезанных CSF.

В ключах переводов специальные символы записываются как `\x3d` для `=`,
`\x5b` для `[`, `\x5d` для `]`, `\x3b` для `;`, а табуляция и переносы — как
`\t`, `\n`, `\r`. Не используйте `;` внутри значений: INI-парсер считает его
началом комментария. Все файлы переводов должны быть в UTF-8.
